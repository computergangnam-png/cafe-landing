# ☕ cafe-landing

'모닝빈 카페'를 소개하는 간단한 카페 랜딩 페이지입니다. HTML과 CSS만으로 만들어져 별도의 설치나 빌드 없이 바로 열어볼 수 있습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (메뉴 바, 히어로, 대표 메뉴, 소개, 오시는 길, 푸터) |
| `style.css` | 페이지 스타일 (모바일 화면 대응 포함) |

## 실행 방법

1. 이 레포를 클론하거나 다운로드합니다.
2. `index.html`을 브라우저에서 엽니다.

## 참고

- 카페 이름, 메뉴, 가격, 주소, 전화번호는 모두 예시 데이터입니다. 실제 정보에 맞게 `index.html`에서 수정하세요.
